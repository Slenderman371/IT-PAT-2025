# IT-PAT-2025
High school IT Practical Assesment Task (PAT), 2025

Project overview:
A transport management application designed to manages vehicles, routes and shipments. It supports three roles: Admin, dispatcher and driver, each with specific permissions, requirements and activities. The system will store data in a small relational database and use arrays, SQL, OOP, and text files. Overview of prject explained in further detail within the word document

Coding/Tech Features:
+ Apllication Logic: Delphi 2010 (object pascal)
+ Database: Microsoft Acces (.acccdb)
+ Query Language: SQL (ADO connectivity)
+ Documentation: Microsoft word

Key features:
* User Authentication: Login system with 3  users/roles, namely, Admin, Dispatcher, Dirver
* Database Integration: Full CRUD operations (Create, Read, Update, Delete) via SQL queries and delphi coding
* Basic input validation: Error handling to prevent invalid inputs & maintain database integrety

Project Structure
+ Documentation: Contains "Phase 1" which is the planning, technical specification, overview of project, project requirements etc (".docx")
+ Sourcecode: Contains Delphi source files (.pas, .dfm, .dpr) and the database files
